# Muscle building

Pick the muscles for a session, check the equipment you have, and the page lists movements and a warm-up that cover every muscle you picked. Three or four muscles is a full session. Tap a muscle again to take it off.

Open `index.html` in a browser. Nothing to install.

The figure is rendered from [Z-Anatomy](https://www.z-anatomy.com/) (CC BY-SA 4.0), which builds on [BodyParts3D](https://lifesciencedb.jp/bp3d/) (CC BY-SA 2.1 JP). See `LICENSE-ASSETS.md`. Running `tools/build-figure.sh` rebuilds the images and the click map. It needs Blender, `cwebp`, and node.
